## 🚀 Como Executar

### Pré-requisito
- Java 11 ou superior instalado (`java -version`)

### 1. Download
Baixe a versão mais recente na aba [Releases](../../releases).

### 2. Uso por Sistema Operacional

#### 🐧 Linux / 🍎 macOS
```bash
# Dar permissão de execução (apenas na primeira vez)
chmod +x cconversor

# Executar
./cconversor -c usd brl 100
